# Python Tkinter Calculator

A simple GUI calculator built using Python and Tkinter. Features a dark-themed interface with basic arithmetic operations including addition, subtraction, multiplication, and division.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear button
- Dark-themed user interface

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python Calculator.py
```
